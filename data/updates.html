WMB+ can continue to run as its own access point for local setup and manual OTA uploads. Keep the scale powered and close to WiFi during upload. A successful update automatically restarts the scale.

Current OTA is manual browser-upload OTA: download the matching WMB+ release asset separately, then upload the -app.bin or -littlefs.bin file here. GitHub self-update from the scale is planned but not implemented yet. Access-point-only mode can serve this page and accept manual uploads.

App firmware OTA requires the new dual-OTA partition table. If this device was flashed with the older single-app layout, flash the factory image once over USB; future app updates can then happen from this page.

App Firmware OTA

Upload the WMB+ app firmware `.bin`, usually the release asset ending in -app.bin.

Web UI / LittleFS OTA

Upload the LittleFS filesystem image `.bin`, usually the release asset ending in -littlefs.bin. This updates dashboard/settings pages without changing the app firmware.
