Battery Settings

mAh

Used for learned runtime, charge-time, and current estimates. Default is 700 mAh; set this to your actual battery, for example 1000 mAh.

V

ADC-backed boards sleep below this voltage. Default is 3.45V.

%

Fuel-gauge boards sleep below this state of charge. Default is 7%.

Auto Sleep

Automatically put the scale to sleep after a period of inactivity. The timer resets whenever the weight changes beyond the drift threshold.

seconds

How long the weight must be stable before the scale sleeps (min 10s).

grams

Weight change within this value is treated as drift and ignored. The timer only resets when weight changes by more than this amount.
